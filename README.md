EXPERIMENT NO: 3.1

CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION


1. AIM

To create a three-dimensional (3D) solid model of the given component by interpreting its orthographic
projections and using Autodesk Fusion 360 software. 


2. SOFTWARE AND SYSTEM REQUIREMENTS

Software Required: Autodesk Fusion 360. System Requirements:

1. Operating System: Windows 10.
2. RAM: 16 GB.
3. Graphics: Integrated graphics with 1 GB or more graphics memory recommended.
4. Internet Download Speed: 2.5 Mbps or faster.
5. Internet Upload Speed: 500 Kbps or faster.


  
3. INTRODUCTION

Orthographic projection is a method of representing a three-dimensional object through two-dimensional views, such as front, top and side views. These views provide information about the shape, size and position of the
different features of a component. Autodesk Fusion 360 is a computer-aided design (CAD) application used to create, edit and visualize 3D models. In this experiment, the given orthographic drawing is studied and its main features are constructed using
sketching tools and solid modelling commands. The sketches are dimensioned and modified as required, and the
Extrude command is used to convert the 2D profiles into a 3D solid. The finished model is then presented on an
ISO-standard drawing sheet. 


4. TOOLS AND COMMANDS USED

 Create Sketch: Starts a new 2D sketch on a selected plane or flat face. 
 
 Sketch Plane: Provides the reference surface on which the required profiles are drawn. 
 
 Line and Rectangle: Create straight edges and rectangular profiles. 
 
 Circle: Creates circular profiles for holes and cylindrical features.  
 
 Arc: Creates curved portions of the component wherever required. 
 
 Trim and Modify Tools: Remove unwanted sketch portions and adjust profiles. 
 
 Dimension: Specifies the required size and position of sketch geometry. 
 
 Inspect: Checks distances and dimensions in the model.  
 
 Finish Sketch: Completes the active sketch and returns to the modelling workspace. 
 
 Extrude: Adds depth to a closed sketch profile to create a 3D solid feature. 
 
 Drawing Workspace: Creates technical drawings with orthographic, section and isometric views.



5. PROCEDURE

Step 1: Open Autodesk Fusion 360

Launch Autodesk Fusion 360 and create a new design file. Ensure that the Design workspace is active so that
sketching and solid modelling commands are available. 

Step 2: Start a New Sketch

Select Sketch and then choose Create Sketch. This activates the sketch environment, where the two-dimensional
profiles can be drawn. 

Step 3: Select the Sketch Plane

Choose a suitable reference plane, such as the Front, Top or Side plane, according to the orientation of the given
orthographic drawing. The selected plane becomes the base for the first sketch. 


Step 4: Draw the Main Profile

Use sketching tools such as Line, Rectangle, Circle and Arc to draw the main outline of the component. Refer to
the orthographic views to understand the overall shape and the relative positions of its features. 


Step 5: Add the Internal and Circular Features

Create the circular profiles and openings shown in the drawing. Position each circle carefully with respect to the
component outline and use the given dimensions to define its size and location. 

Step 6: Modify and Refine the Sketch

Use sketch modification tools such as Trim, Extend, Mirror and Move, wherever required, to remove unwanted
portions and refine the geometry. Ensure that profiles intended for solid modelling are properly closed. 

Step 7: Apply Dimensions

Use the Sketch Dimension command to enter the required linear and diameter dimensions. Check the positions
and sizes of the features against the supplied orthographic drawing. 

Step 8: Inspect the Sketch

Use the Inspect tools to verify important distances and measurements. Compare the sketch with the given
drawing to ensure that the main features and their relative positions are represented correctly. 

Step 9: Finish the Sketch

After completing the geometry and dimensions, select Finish Sketch. The completed 2D profile is now ready to
be used for creating solid features. 


Step 10: Convert the Sketch into a 3D Solid

Select Extrude from the Solid workspace. Choose the required closed sketch profile and enter the extrusion
distance according to the drawing. Confirm the operation to create the first solid feature. 


Step 11: Create Additional Features

Create new sketches on the appropriate faces or planes to form the remaining features, such as raised portions, cylindrical sections and holes. Use Extrude to add material and an appropriate cut operation to create openings
or recesses. Repeat the sketch-and-feature process until the component matches the given drawing.


Step 12: Review the 3D Model

Use the ViewCube and orbit controls to inspect the completed component from different directions. Check that
the overall shape, holes and other features correspond to the orthographic projections. Figure 1: Completed 3D solid model created using Autodesk Fusion 360

Step 13: Create the Technical Drawing

After completing the 3D model, open the Drawing workspace and create a drawing from the design. Select the

Step 14: Place the Required Views

Place the necessary orthographic views on the drawing sheet. Add the sectional view where required to show
internal details, and include an isometric view to represent the overall three-dimensional shape. 


Step 15: Add Dimensions and Save the Drawing

Add the required linear, diameter and other dimensions, along with centre lines and section markings. Arrange
the views and dimensions clearly so that they can be read easily. Review the drawing and save the completed
